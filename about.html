SSTRIIDGAMES

Good games. One place.

STRIID Games is a catalogue of browser games organised by genre. Save favourites and recent games on your device, or give a game a like to help other players find it.

Game sources

The catalogue includes public game listings from Classroom 6x, retrieved on 15 October 2026, and the original Parcoil template catalogue. STRIID is an independent project. Games, trademarks and artwork belong to their respective owners. The number of listings is not a claim that every game has been tested or is currently available.

Third-party games load from their original asset providers in an isolated player when supported. Some games require their source page, a desktop browser, or unavailable online services. The source link under each player lets you try the original page. Multiplayer support depends on the provider.

The Eaglercraft 26.3 browser build was provided by the site owner. It is hosted locally at /eagler/. This site is not affiliated with Mojang or Microsoft.

Favourites and community likes

Hearts save favourites in your browser, and recent games stay on that device. Community likes use an anonymous browser cookie and a shared Cloudflare database when connected. One active like per browser and game is recorded. Basic rate limiting helps reduce spam; these are casual community rankings, not verified votes from unique people.

If community voting is unavailable, the site says so and continues to support personal favourites. No sample votes or invented rankings are displayed.
